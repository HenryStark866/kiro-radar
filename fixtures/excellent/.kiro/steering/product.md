# Product

Kiro Radar scans a repository and scores how well it uses Kiro in 10 dimensions,
providing evidence and the next actionable move for each dimension.

- Users: anyone using Kiro who wants to improve their configuration.
- Value: turns "I use many tools" into a measurable, actionable score.
- Core principle: presence is not quality. An empty file scores 0.
- Final proof: the project scans itself in the demo.
- Mandatory disclaimer: community project, not official Kiro nor AWS.
