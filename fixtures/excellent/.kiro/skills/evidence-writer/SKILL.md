# Evidence Writer Skill

## Steps

1. Identify the tool or Kiro feature used (hook, skill, agent, workflow, MCP, etc).
2. Add a row to docs/TOOLS-MATRIX.md with: tool name, file path, proof (test or log).
3. Reference the commit or test that demonstrates it works.
4. Never claim a tool works without a passing test.
