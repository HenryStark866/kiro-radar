# Kiro Radar Power

Installable Kiro Power that adds `kiro-radar scan` as a built-in command.
Scans the current repository and displays a score dashboard in your terminal.

## Install

```bash
kiro power install kiro-radar
```

## Usage

After installation, run `kiro-radar scan` from any repository root.

## Dimensions Scored

agents, hooks, mcp, powers, protection, skills, specs, steering, traceability, workflows.
