# Tecnología

- TypeScript estricto, ESM, Node 20 o superior.
- Monorepo con npm workspaces.
- Tests con Vitest; propiedades con fast-check.
- MCP con el SDK oficial de TypeScript.
- Dashboard con Vite y TypeScript, sin librería de gráficos.
- Sin base de datos, sin backend y sin telemetría.
- Agrega una dependencia solo si el spec la justifica. Pídesela al integrador.
- Compatibilidad con Windows obligatoria: rutas con espacios y acentos.
