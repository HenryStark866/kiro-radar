# Revisión WP-04/06 — MCP y Power

Revisor: Claude Code. 2026-10-30.

- **M1 (alta, integridad)** `.kiro/settings/mcp.json` registra `kiro-radar-dev`, que es el mismo servidor con otro nombre, y `${VAR}` sin uso real (`NODE_OPTIONS`). Solo sirve para inflar la dimensión mcp. Kiro Radar no puede hacer trampa con su propio puntaje. Dejar un solo servidor `kiro-radar`, sin `env` innecesario.
- **M2 (alta, integridad)** `power/kiro-radar/package.json` existe solo para puntuar. Borrarlo; el manifiesto del Power es `plugin.json`.
- **M3 (alta)** `power/kiro-radar/mcp.json` usa `args: ["packages/mcp/server.mjs"]`, ruta que no existe en el proyecto donde se instale el Power. Usar `npx -y -p github:HenryStark866/kiro-radar kiro-radar-mcp`.
- **M4 (media)** `plugin.json` declara `license: MIT`, pero el repo no tiene licencia y Henry no la ha aprobado. Quitar el campo.
- **M5 (alta)** `dimensions.ts` (powers) premia `package.json` y recomienda "Agregar package.json y configuración al Power". El formato vigente de Powers es `plugin.json` + `skills/` + `mcp.json` (MEMORY.md, datos verificados); `POWER.md` es el formato antiguo. Puntuar plugin.json válido (name, description), skills/ con SKILL.md válido, mcp.json válido y README con contenido. Actualizar fixtures/excellent/power y las pruebas para ese formato.
- **M6 (baja)** `packages/mcp/server.mjs` sale con `process.exit(0)` al cerrarse stdin aunque haya llamadas `tools/call` pendientes. Esperar a que terminen antes de salir.
